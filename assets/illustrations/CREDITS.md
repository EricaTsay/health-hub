## 已做的修改

- 主色：unDraw 預設 accent `#6c63ff` → 品牌深綠 `#17603f`；次要 `#575a89` → `#2e7d51`。
- 膚色與中性灰階維持原樣，確保人物與情境仍清晰可辨。

原始（未改色）檔案透過 unDraw 搜尋 API `https://undraw.co/api/search?q=<關鍵字>` 取得的 `media` 網址下載。
